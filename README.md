## Pitch line

> Kevin_Changed_It_Again_FFS

Nama WiFi sebagai pesan pasif-agresif ke roommate. Karakter:
Kevin. Peristiwa: mengganti password lagi. Emosi: FFS.
Kata-END "FFS" adalah punch-nya — eskalasi "again" + ledakan
"FFS" menutup kalimat sekaligus mengimplikasikan sejarah panjang
sengketa wifi di rumah itu.
